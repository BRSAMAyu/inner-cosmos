## 本增量落地的服务端契约（FailurePreservesInputContractTest）

1. **失败保留输入**：信件发送被安全硬拦 → 草稿保持 DRAFT、正文原样、属主仍可编辑重试
2. **跨账户不可读**：他人读草稿 → UNAUTHORIZED（离线缓存的账户隔离由 web Keystore 草稿存储承担，已在 web 测试锚点）
3. **成功才可见**：SENT 之后才有 outbox 视图与承诺时刻（CP-33 VO）
