# CP-07 隐私影响评估（PIA）与同意产品合同规格 v1

> 状态：DRAFT v1（2026-09-06）。蓝图 §5.1"个人信息与敏感信息"行的可执行化。
> 本文件是下一轮编码的规格输入；法务复核与生效版本由所有者签字（外部门）。

## 1. 数据清单与敏感分类（按隐私分层）

| 层 | 数据 | PIPL 分类 | 处理目的 | 合法基础 | 现有执行点 |
|---|---|---|---|---|---|
| P0 原始对话/语音 | 文字与转写正文、录音元数据 | 一般个人信息；健康/心理相关内容可能构成敏感 | 提供核心服务（履行合同所必需）+ 安全守护 | 必需 + 安全法定义务；**永不出境/永入第三方训练** | tb_dialog_*；标识办法覆盖 AI 回复 |
| P0 声纹/语音特征 | ASR/TTS 处理的语音 | **敏感（生物识别相关）** | 语音交互 | **单独同意**（语音开关，默认文字） | CP-27 前须落同意位 |
| P1 记忆/画像/情绪 | MemoryCard、ThoughtFragment、EmotionTrace、信念/画像 | 部分为**敏感（健康/心理推断）** | 用户自理解；派生控制 | 履约 + 明确同意（分层授权） | consentScope（LOCAL_ONLY/NO_EXTERNAL_PROCESSING/SIMULATOR_AUTHORIZED） |
| P1 向量/嵌入 | 记忆与画像向量 | 个人信息派生 | 检索/匹配 | 与源记忆同等约束（撤回联动） | MemoryEmbeddingMapper 已按 consentScope 过滤 |
| P2 共鸣体 | 授权侧面对外表达 | 个人信息（对外提供） | 用户授权的公开展示 | **明确授权**（逐项、可撤回、可预览） | DataUseGrant（purpose=CAPSULE_COMPILE，版本化）+ 边界 |
| P3 社交 | 慢信/好友/群组 | 个人信息（通信内容） | 用户间通信 | 履约；审核治理法定义务 | LetterSafetyFilter + 审核 |
| 账户/身份 | 用户名、出生日期（成人门槛）、设备、IP | 一般个人信息；出生日期+年龄为**敏感关联** | 准入/安全/多设备 | 履约 + 法定义务（防未成年） | V37 birth_date；CP-13 升级核验 |
| 支付 | 订单/渠道流水 | 个人信息（金融相关） | 交易履约 | 履约 + 监管 | CP-45 |
| 遥测/指标 | CP-03 事件（无 P0 正文，白名单 props） | 一般个人信息（去标识聚合为主） | 服务质量衡量 | 默认必需聚合 + 可拒绝（tb_analysis_consent） | MetricEventService |
| 危机/安全记录 | SafetyEvent（等级/类型，无正文） | 敏感关联 | 法定安全义务 | 法定义务优先 | SafetyServiceImpl |

## 4. 同意产品合同规格（下轮编码输入）

- **存储**：`tb_consent_record`（user_id, purpose_code, status GRANTED/DECLINED, version, granted_at, revoked_at, evidence_source）+ 迁移现有 DataUseGrant/consentScope/analysis_consent 到统一读模型（不重写历史行）。
- **API**：`GET /api/me/consents`（分组呈现：必需/可选/敏感）、`POST /api/me/consents/{purpose}`（授予/拒绝/重授）、撤回统一走既有权利链并产生 RIGHTS_ACTION_COMPLETED。
- **执行点**：模型网关出站前核验 AI_PROVIDER_EGRESS（拒绝→明确提示哪些功能不可用，不静默降级）；共鸣体编译沿用 DataUseGrant；指标沿用分析开关。
- **重同意**：version 变更且语义扩大 → 服务端标记 STALE，下次使用前引导重授；语义不变仅措辞 → 静默续期留痕。
- **J01 渐进同意**：首次价值路径只请求当时必需项（CORE_SERVICE + 语音可选），其余在使用到时再请求——不打包。
- **未成年人/危机法定处理**：不属于可拒绝同意（法定义务），在同意中心以"依法处理"分组只读呈现。

## 5. 风险登记（PIA）

| 风险 | 等级 | 缓解 |
|---|---|---|
| 心理推断被用于定价/差异化（自动化决策） | 高 | 政策禁止 + K3/CP-47 定价不引用画像维度 + 审计（CP-63） |
| 画像跨层泄露（P1→P2 越权） | 高 | 现有 P1P2 边界测试 + CP-14/30 红队 |
| 已撤回数据经备份复活 | 高 | CP-15 撤回防复活 + 备份生命周期 |
| 语音数据过度留存 | 中 | CP-27 保留策略 + 单独同意 |
| 指标事件间接识别 | 中 | 白名单 props + 注销 rollup + 无 P0 |
