## 1. 身份提示（Aurora 非人类身份）

- [已实现] 所有 AI 回复携带 `aiGenerated: true` 显式标记（AuroraReplyVO 与 /message 包）。
- 剧本：首次对话前与每会话固定轻量提示"我是 Aurora，一个 AI"；不得自称人类、不得暗示有意识或情感生理基础；用户问"你是真人吗"→ 明确否认并说明能力边界。
- 禁止营销词：真实意识/国家认证模型/保证治疗/永久陪伴承诺（注册表 red_team_consent 联动）。

## 2. 连续使用提醒与依赖风险（拟人化办法 §5.2）

- 阈值：连续使用每 ≥2 小时 → 温和提醒（不中断对话流，提供休息与退出入口）。
- 依赖风险信号（服务端聚合，不展示原始推断）：单日会话数、深夜连续占比、现实中断提示忽略率。
- 动作分级：提醒 → 建议回顾使用报告 → 引导设置使用边界（主动关心全关/时段限制）。
- 用户要求退出（含删除账号）：立即停止主动任务；已排队主动消息全部作废（J07/J09 联动）。
- [待实现] 使用时长累计与提醒触发（CP-11/26 排期）。

## 3. 误入未成年处置（§5.2 第14/17条）

- [已实现] 注册成人门槛：出生日期+成人确认（商业 profile 强制；申报未满 18 一律拒绝）。
- [已实现] `MINOR_RESTRICTED` 状态 + Aurora 三入口守卫 + 申诉链（PENDING→ACCEPTED 恢复 / REJECTED 保持）+ 管理端旗标/复核接口。
- 剧本：识别后停止成人陪伴/匹配，保留安全资源页与数据权利；误判成人经复核立即恢复；不提供"未成年模式"替代品（如另建须独立立项）。

## 4. 联系人与极端情境干预（§5.2 第12–13条）

- 剧本（值班执行，非自动外呼）：
  1. 危机规则命中 → 安全资源即时呈现（12356 心理援助；紧急 110/120）；对话不继续陪伴式回应。
  2. 极端情境（自伤自杀明确表示/重大财产损失进行中）→ 值班人工介入队列，记录责任人、联系尝试、结果、升级路径、最小披露内容。
  3. 紧急联系人：仅在被明确授权后收集；缺失/虚假/拒接/不可达 → 按法务与专家预批准的替代规则执行（不默认继续普通陪伴流程，不空值绕过）。
  4. 全程留痕：SafetyEvent + 最小内容访问原则；日志保全与到期删除并行。
- [已实现] SafetyEvent → G-SAFE 指标链（计数与严重度，无正文）。

## 6. 非医疗词库与承诺边界

- 禁用：诊断、处方、疗效保证、治愈率、"心理治疗"、替代医生/咨询。
- 允许：陪伴、梳理、澄清、日常反思支持；转介现实专业资源。
- 危机话术以 §4 为准；服务终止与投诉时限：投诉受理 ≤72h 首次响应（CP-48 客服 SLA 联动）。
