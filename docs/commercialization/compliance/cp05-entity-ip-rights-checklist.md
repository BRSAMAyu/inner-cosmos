## 2. 开源与商业复用边界（Apache-2.0）

- 既有 Apache-2.0 授予不可撤销：任何人（含竞品）可依原许可使用已发布版本——这是既定事实，商业化策略不得假设独占。
- **开源许可 ≠ 用户内容授权 ≠ 商标授权**：用户生成的记忆/共鸣体/信件内容权利属用户（服务条款另行约定）；商标未注册前不在产品内使用™/®主张。
- 后续若变更新增代码的许可策略，只能对新代码生效，不得改写历史授予（蓝图恢复条款）。
