# Inner Cosmos 5 分钟核心产品 Demo

> 目标：五分钟内让观众亲手感受到“关系已经生活了一段时间的 Aurora”、可追溯记忆、
> 策展式共鸣体和一条真实的人际连接。三套故事是预先创作的数据模板；进入时系统会
> 为每个浏览器真实克隆独立私密沙盒。不要宣称它们是从现场几十秒训练出来的模型。

## 演示前唯一入口

投屏和二维码都只展示公网 `/app/aurora/`。不要公开 `demo/demo123`、`river` 或
`cloud` 的密码。观众点“有生活痕迹的体验”中的任一故事，服务端会生成独立的
`SANDBOX` owner；他们改昵称、聊天、看记忆或操作私有共鸣体都不会写到其他观众的数据。

需要参加真人社交的观众另开无痕窗口注册 HUMAN 账户，使用自己容易辨认的唯一用户名。

## 0:00–1:35：成熟关系，不是通用聊天机器人

1. 主讲人选择 **Lin Che**。进入按钮会依次显示“复制私密记忆 → 编织表达与边界 →
   生成私有共鸣体”，随后直接进入成熟状态，不弹新手功能导览。
2. 打开“内宇宙”，点一颗星，先看摘要，再展开来源，强调“结论可以追溯，也可以纠正”。
3. 回到 Aurora，粘贴这条黄金提示：

   > 我又想把明天的展示继续磨到凌晨。你应该记得我以前说过，我不想再用透支自己来证明认真。别顺着我，也别给我一堆清单；结合现在的时间，帮我做一个诚实的选择。

4. 讲解屏幕上的真实阶段：快速接住 → 理解 → 组织回应。期望回应必须同时体现：
   - 引用已授权的既有记忆，而不是编造；
   - 感知当前时间；
   - 不迎合“继续熬夜”；
   - 只给一个低后悔选择；
   - 保留 Aurora 的关系语气，而不是客服式复述。

如果 Provider 最终回复超过 35 秒，保留前景回应并继续下一段；不要重复发送。

## 1:35–2:25：三个故事，三种真正不同的“人”

展开“体验角色”依次切到 Shen Yan 和 Xia Yu。只展示每人的一颗记忆星、一个信念和
私有共鸣体，不再各跑一次 Aurora。

- Shen Yan：归属、迁移、创作，表达留白，不急着下结论。
- Xia Yu：照顾、疲惫、边界，温柔但会指出自我消耗。
- Lin Che：创造、标准、行动，允许被挑战，不把透支浪漫化。

强调：三者结构同样完整，但画像、关系模型、信念和慢信线索不同；不是换昵称的同一份数据。

## 2:25–3:05：策展式共鸣体

进入“共鸣 → 我的共鸣体”，展示刚才沙盒中已经编织好的私有 v1：

1. 授权的记忆来源；
2. 表达方式与边界；
3. 私有状态（不会自动发布）。

这里的正确讲法是：

> “我们预先策展了三套足够丰富的生活资料。刚才系统把所选模板实时克隆为这台设备独有的
> 私密沙盒，并绑定已编译的 Genome；现场不假装用几十秒重新训练人格。”

新注册用户进入广场时看到的是三份固定 canonical showcase，而不是几十个观众的私有克隆，
所以广场不会被 Demo 垃圾数据刷屏。

## 3:05–3:45：从空白开始认识 Aurora

志愿者 A 在无痕窗口注册新账户。首次进入只做 45–60 秒轻校准：

- 希望 Aurora 温柔、清晰还是直接；
- 主动程度；
- 陪伴还是深入；
- 最近关注的生活主题和一句可选背景。

保存后输入框会出现一句可编辑的第一句话。它是草稿，不会自动替用户发送。发送后展示：
新账户没有伪造旧记忆，Aurora 从昵称、当下背景和本轮语言开始建立关系。

## 3:45–5:00：全场共同的小组

1. 所有已注册观众进入“连接 → 小组”，点击“加入现场共同星球”。
2. 投屏打开同一个小组。观众用自己的用户名自由发送一句话；群消息通过真实接口写入，
   并以 5 秒短轮询持续出现在投屏上。
3. 强调这是自愿加入的 HUMAN 房间，三套模板和个人 SANDBOX 不会加入，群消息也不会进入
   Aurora 的私密记忆。
4. 时间允许再用“认识人”按完整用户名精确找到一位观众，展示好友邀请和 `DEMO_30S`
   慢信；慢信状态可以留到可观测性 Hero 场景继续展示。

## 30–50 人现场流量编排

- 50 人可以同时进入三故事、浏览 Aurora 历史、记忆星空和公共共鸣体。
- 不要求 50 人在同一秒都触发深度双核生成。简单首轮由 adaptive 单核处理；记忆、歧义、
  中断和安全敏感轮次保留双核。主持人按每批 8–12 人引导发送 Aurora 消息。
- 真人社交优先让全场加入同一个现场小组；一对一时直接按完整用户名精确搜索。
- 彩排前运行：

  ```powershell
  Set-Location "D:\code\inner cosmos"
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\demo\test-30-user-burst.ps1 `
    -Origin "<当前公网 Origin>" -UserCount 50 -SandboxEntryUsers 50 -ThrottleLimit 12
  ```

只有新报告中 `sandboxIsolation.isolated=true`、HTTP 无 5xx/429、真实 Provider 无 fallback，
且社交连接环完成，才可以说“本环境已通过 50 人彩排”。代码和单测通过不等于容量通过。

## 现场兜底

- Aurora 慢：不重复发送；讲解前景回应和阶段状态，转去星空，稍后回来。
- 找不到同伴：使用精确用户名，不用滚动最近列表。
- 慢信未到：先展示群消息/此刻聊聊，把投递状态留到可观测性面板。
- 任一观众误入共享账号：立即退出，重新从三故事入口进入个人沙盒。
- 演示结束：运行 public-demo stop/cleanup，并保存本次 burst JSON、traceId 和时间戳。
