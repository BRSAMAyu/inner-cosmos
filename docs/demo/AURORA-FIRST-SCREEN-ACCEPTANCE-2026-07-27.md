# Aurora 首屏重构验收记录（2026-07-27）

## 产品合同

- 「今天」只把导航、对话工具栏、消息记录和输入区放进首个视口。
- 有历史消息时不显示欢迎大标题；球体只作为低透明背景，不参与布局。
- Aurora 状态、模式、历史和新对话共用一条工具栏。
- 只有消息记录可以纵向滚动；输入区始终留在主舞台末端。
- Demo 角色、回来约定等次级功能默认收进「对话之外」，不再挤压消息区。
- 首次引导在桌面使用右侧面板，在窄屏使用底部面板；步骤切换不得改变面板尺寸。
